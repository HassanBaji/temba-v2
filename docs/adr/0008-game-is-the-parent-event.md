# Game is the parent event; Match is the contest

The old Game row was one playable contest, and “match” was a forbidden synonym. The product needs a parent that can hold one contest or many (Friendly game, Americano, Friendly tournament). Keeping Game as the contest and adding a parent named Event was rejected; nesting a second contest noun under Game without renaming was rejected. **Game** is the parent event; **Match** is the playable contest. Lists, Group delete, and Game team move with that rename.
