# Archivo variable font with the width axis, replacing Geist

Home's redesign sets big numerals and Level bands expanded (`wdth` 112–118, `wght` 700) while body text stays at `wdth` 100, so the width axis carries the typographic hierarchy that a second family or a display face would otherwise carry. Archivo on Google Fonts is variable across `wdth` 62–125 and `wght` 100–900, loads through `next/font/google` as one self-hosted file, and replaces Geist as `--font-sans` app-wide; `font-feature-settings: "tnum" 1` is set globally so numerals do not jitter when a countdown or rating updates.

**Considered Options**: keep Geist and add Archivo as a scoped display face; keep Geist and fake the expanded grades with letter-spacing; Archivo app-wide. Two sans families on one product reads as indecision and doubles the font payload on every route, and letter-spacing does not reproduce a true width axis. Rejected app-wide risk is accepted deliberately: the swap restyles every existing route, so it ships as its own reviewable ticket ahead of the Home work rather than inside it. Note for future readers: `next/font/google` includes `wght` by default and **rejects** it in `axes`, so the call is `axes: ["wdth"]` — listing both axes is an error, not a stricter version of the same thing.
