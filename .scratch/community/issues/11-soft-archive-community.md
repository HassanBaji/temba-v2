# 11: Soft-archive Community

**What to build:** Owner or Admin Soft-archive a live Community. It and its Club Groups leave the Directory and hide together; Club Groups stay attached (they do not become Loose Groups). Members still see history and Games. Non-members see an archived state, not a live join page. New joins, requests, Email invites, and Invite links stop (consume refused; tokens kept unless staff rotate). Unarchive restores listing and join rules, including the same Invite link token unless rotated. Loose Groups are untouched. Public pickup Games on those Club Groups are not offered as live.

**Blocked by:** 04: Admit to Community Private (Email invite + Invite link); 05: Club Group Public: create, join, leave Group; 06: Loose Group Public: create and join via URL

**Status:** ready-for-agent

**Parent:** #1 Community: clubs, Groups, sports, and Private invites

- [ ] Owner or Admin can Soft-archive a live Community; Members cannot
- [ ] The Community disappears from the Directory; Club Groups stay Club Groups and hide with it (they do not become Loose Groups)
- [ ] Members can still open the Community and its Club Groups and see history and Games
- [ ] Non-members hitting a deep link see archived, not a live join page and not a never-existed empty 404
- [ ] New requests, Email invites, and Invite links refuse consume while archived; tokens are not auto-revoked
- [ ] Unarchive restores listing and join rules; the same Invite link token works unless staff rotated it
- [ ] Loose Groups are untouched
- [ ] Games whose Group’s Community is Soft-archived do not appear as live public pickup; the Game public flag on the row is not flipped
- [ ] Leave is still not Soft-archive (Owner lifecycle from 09 still holds)
