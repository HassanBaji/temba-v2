# 06: Loose Group Public: create and join via URL

**What to build:** Any authenticated User creates a Loose Group Public (no Community) with a name and public type only (no sport field; the App stores padel) and is a member. Another authenticated User joins from the Group URL. It does not appear in the Directory and is not an Invite link.

**Blocked by:** 01: Unique Group membership and Game-on-Group restrict

**Status:** ready-for-agent

**Parent:** #1 Community: clubs, Groups, sports, and Private invites

- [ ] Any authenticated User can create a Loose Group Public with a name and public type only, with no Community parent; the App stores padel; the creator is a Group member
- [ ] Loose Group create has no sport field
- [ ] Another authenticated User can join immediately via the Group URL
- [ ] Loose Group Public does not appear in the Directory
- [ ] Join does not use an Invite link
- [ ] The same User cannot join the same Group twice
