# 03: Request to join Community Public

**What to build:** A User requests to join a live Community Public (including an empty one). Owner or Admin approve and the requester becomes a Member; reject and they may re-request; ignore leaves the request pending. Members cannot approve. Community Public has no Email invite and no Invite link.

**Blocked by:** 02: Create Community and Directory

**Status:** ready-for-agent

**Parent:** #1 Community: clubs, Groups, sports, and Private invites

- [ ] An authenticated User can request to join a live Community Public, including one with zero Groups, with no message and no expiry
- [ ] Owner or Admin approve → requester is a Member immediately
- [ ] Owner or Admin reject → requester is not a Member and may re-request
- [ ] Owner or Admin may leave a request pending (ignore)
- [ ] A Member who is not Owner or Admin cannot approve, reject, or otherwise admit people
- [ ] Community Public has no Email invite and no Invite link
- [ ] Community Private still has no request-to-join path
