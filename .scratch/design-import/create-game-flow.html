Dropdowns to picks
Group, court, start time, duration and level all fit on screen as chips, so the whole form is four taps instead of nine sheets.
Header as preview
The black header carries the game being built, in the same type as the game detail screen, so the organizer reads the result rather than the inputs.
One shell, two branches
The type pick in step 1 decides what steps 2 to 4 hold. Group, venue, day and price are shared; teams, format and the schedule fit line only appear for a tournament.
