# Temba UI/UX audit — 2026-09-28

Scope: every route in `apps/temba` (App Router), every shared component, and the design tokens.
Status legend: **Open** · **Fixed** · **Skipped** (reason) · **Needs design decision**.
Severity: **High** = broken/unreachable, a11y blocker, data loss, unconfirmed destructive action · **Medium** = inconsistency users notice, missing state, <44px primary target · **Low** = polish.

Tickets: each finding maps to one fix batch (`T1`…`T25`). Batches fix the root (token / primitive / shared component) once, not per screen. Linear ids are in [§7](#7-fix-batches-linear-tickets). Linear's free-plan issue limit was hit after TEM-279, so T10–T25 exist only in this file.

## 0. Method and limits

- Four parallel code audits (primitives + chrome, Games, Groups/Communities/Teams/Venues, Home/You/auth/invites), each claim checked against source. High findings were re-verified by hand.
- The App was run locally (`pnpm --filter temba dev`, local Postgres — the Railway `DATABASE_URL` was deliberately not used) and screenshotted with Playwright at 360 / 768 / 1024 / 1440.
- **Limit:** this environment's network policy blocks Clerk (`api.clerk.com`, `*.clerk.accounts.dev`), so no session could be created. Signed-in screens were checked visually only through the dev fixture previews (`/dashboard/design/{home,game-details,tournament}`, which render the real Home / Game / Tournament components and the real shell). Everything else was audited from code. Screenshots: `.scratch/ui-audit/shots-2026-09/`.
- Previous audit in `.scratch/ui-audit/*.md` predates the black/white redesign and is stale.

## 2. Design system actually in use

- **Colour — two parallel token sets.** Semantic shadcn tokens (`primary #0A0A0A`, `background #FFFFFF`, `muted-foreground #6E6E6E`, `border #E5E5E2`, `input oklch(.89)`, destructive/success/warning + `-subtle`) **and** the "Home-only" set (`ink #000`, `paper`, `rule #E6E6E6`, `wash #F4F4F4`, `dim #8E8E8E`, `dimrule`, `raised`). The Home set has spread to 65 non-Home files (`border-rule` 181 vs `border-border` 13; `bg-paper` 58 vs `bg-card` 5). Specs in force: `.scratch/retire-volt-accent` (black/white only) and `.scratch/home-level-redesign`.
- **Type:** Archivo (variable, `font-expanded`), Geist Mono micro-labels. Named scale `eyebrow 12 / meta 13 / body 15 / lead 17 / title 19 / h2 24 / h1 28 / h1-lg 32 / display 36 / hero 48` competes with Tailwind `text-sm` (134), `text-base` (36), `text-xs` (35) and 194 `text-[Npx]`.
- **Radius:** scale `sm 8 / md 10 / lg 12 / xl 16`, but the de-facto card radius is off-scale `rounded-[14px]` (×57).
- **Spacing:** Tailwind 4px scale plus a parallel 18 / 22 / 26px system (`px-[22px]` ×38).
- **Shadows:** almost none (borders, not shadows — matches spec).
- **Icons:** Lucide only; sizes and strokes vary per role.
- **Dominant patterns (treated as the standard):** hairline-bordered white surfaces, black primary fill, ink hero cards, hatch = "not yet", `RowList`/`ListRow`, `EmptyState`/`ErrorState`/`Skeleton`, 44px `Button` default.
